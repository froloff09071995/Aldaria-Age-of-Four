# Арка V.1 — Совет

**Статус:** черновик на согласование. **Начало арки V — Война двух источников.**
**Формат:** визуальный сценарий; реплики главного героя (**Тейн**) помечены «ГГ».
**Период:** около трёх недель после того, как погасли Башни.
**Точка завершения:** двадцатая Башня зажжена; у Тейна — карта Ли'Зар.

## Главы

93. [Столица в огне](93-capital-on-fire.md) — беженцы, отец в доспехах, Ведар исчез с ключом; шестой из компании отца.
94. [Совет Четырёх](94-council-of-four.md) — король раскрывает Сферу Совету; «Люди — с ним».
95. [Король](95-the-king.md) — исповедь в саду; «за неё»; «я горжусь тобой».
96. [Башни](96-towers.md) — Сигрун, сорок три разреза Ведара, Тейн зажигает первую Башню Светом Сферы — и Свет убывает.
97. [Цепь света](97-chain-of-light.md) — дом Иларэн отдаёт Свет вдоль границы; Ли'Зар не гасит Башню и отдаёт карту; «Свет — тёплый. Я забыла».

## Новые элементы (предложение)

| Элемент | Суть |
|---|---|
| **Король — Годрик** | Имя (вариант из плана). Публично признаёт тайну Сферы и свою вину. |
| **Шестая из компании отца** | Девушка-человек, целительница; погибла в начале войны. |
| **Тайна Сферы раскрыта Совету** | Зеркало главы 4: ученики теперь внутри зала. |
| **Зажигание Башен** | Сигрун восстанавливает перерезанные руны; Тейн отдаёт Свет Сферы; хранители Иларэн — свой. Свет убывает, Тьма — нет. |
| **Ли'Зар** | Не выполняет приказ, отдаёт карту пути к источнику. Знает, что умрёт, если Салдар потеряет опору. |

## Канонические ограничения

- Совет Четырёх решает общую угрозу совместно (как в главе 4).
- Очищающие башни сделаны по чертежам Сферы.
- Король — Г2: признаёт ошибку.
