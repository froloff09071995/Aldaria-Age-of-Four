# Арка II.1 — Гора

**Статус:** черновик на согласование. **Начало арки II — Город титанов в горе.**
**Формат:** визуальный сценарий; реплики главного героя (**Тейн**) помечены «ГГ».
**Период:** первые полтора месяца в горе. Тейну 17 лет.
**Точка завершения:** отец отвечает: «Найди меня. Сам». До Ярмарки мастеров — два месяца.

## Главы

45. [Как следует](45-properly.md) — Врата горы, Торгар встречает, пир у Хальгрима, «не спрашивай меня — я дал слово».
46. [Экзамен у горна](46-exam-at-the-forge.md) — мастер Дорн, двойной удар с поворотом, «так куют только у Террага».
47. [Руны](47-runes.md) — Сигрун, «взгляд» Тейна на пути маны, руны на телах, торговый класс.
48. [Клеймо](48-the-mark.md) — ниша Террага в Зале Мастеров, рекомендация «двух колец», два профиля.
49. [Перевёрнутое имя](49-reversed-name.md) — ТЕРРАГ / ГАРРЕТ, разговор на поющей лестнице, письмо и ответ отца.

## Новые элементы (предложение)

| Элемент | Суть |
|---|---|
| **Отец — Гаррет; псевдоним — Терраг** | Имя справа налево. Канон: псевдоним — изменённая форма настоящего имени. |
| **Хальгрим** | Правитель титанов, отец Торгара. Знает Террага, держит слово. |
| **Школа Горна** | Название титанской школы. Вступительный экзамен — клинок без руны. |
| **Мастер Дорн** | Старый титан с бельмом, учил отца. |
| **Сигрун** | Титанша-ровесница, лучшая в рунах и торговле; соперница. |
| **Двойной удар с поворотом** | Приём школы великого наставника: им куют и Терраг, и Ведар. |
| **Ниша Террага** | Единственный человек в Зале Мастеров. Рекомендован обществом «двух колец». |
| **Два профиля** | Детское воспоминание Тейна: «одна рука для меча, другая — для дома». |

## Канонические ограничения

- Отец — известный кузнец и артефактор под псевдонимом; два профиля — на обеих руках.
- Тейн учится у титанов ради ремесленной и торговой лицензий.
- Официальная версия о Сфере («разрушилась») не нарушается; никто не связывает её с Тейном.
- Король ещё не появляется в арке.
