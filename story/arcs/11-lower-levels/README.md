# Арка II.2 — Нижние уровни

**Статус:** черновик на согласование.
**Формат:** визуальный сценарий; реплики главного героя (**Тейн**) помечены «ГГ».
**Период:** два месяца перед Ярмаркой мастеров.
**Точка завершения:** Гайя встречает отца.

## Главы

50. [Торговый ряд](50-market-row.md) — торговая практика, лавка деревянных волков, «Гайя... жив?».
51. [Большой и грустный](51-big-and-sad.md) — история Брама и Сайры, роды, приговор рода, письмо Гайе.
52. [Братство Горна](52-brotherhood.md) — семь «живых» клейм, двойной удар открывает дверь, холодная ковка.
53. [Глубокий горн](53-deep-forge.md) — Дорн и Сигрун, архив братства, книга наставника с предупреждением о «втором источнике».
54. [Гайя](54-gaya.md) — приезд Гайи, встреча с отцом на мосту, «Право достойности».

## Новые элементы (предложение)

| Элемент | Суть |
|---|---|
| **Брам** | Отец Гайи; режет деревянных волков на нижнем рынке. |
| **Сайра** | Мать Гайи, сестра Вожака. |
| **Причина приговора** | Сайра умерла при родах (ребёнок с кровью титана); Вожак в горе обвинил Брама. Брам дважды пытался вернуться. |
| **Братство Горна** | Ключ — двойной удар с поворотом; испытание — холодная ковка резца и дорезанная руна горна. Дорн — глава, Сигрун — дозорная. |
| **Книга наставника** | Великий наставник предупреждал о мастере, «думающем о втором источнике»; имя сгорело. Наставник — не предатель. |
| **Гайя и Право достойности** | Намерение вернуть отцу право въезда в степь. Мост к арке IV. |

## Канонические ограничения

- Розыск Брама действует только на территории оборотней; его виновность не доказана.
- Тайные общества разных народов знают друг о друге, но это не единый орден.
- Предательство в проекте Сферы не раскрыто; имя сгорело.
- Второй переход Гайи (титанский) ещё впереди.
