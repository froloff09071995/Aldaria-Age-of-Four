# Арка IV.3 — Туман войны

**Статус:** черновик на согласование. **Финал арки IV — Великая Арена.**
**Формат:** визуальный сценарий; реплики главного героя (**Тейн**) помечены «ГГ».
**Период:** день Кровавой битвы, неделя после, ночь начала войны.
**Точка завершения:** Башни гаснут; письмо отца: «Возвращайся. Начинается».

## Главы

88. [Туман](88-the-fog.md) — бешенство на трибунах; Дарион, Торгар и Знак Клыка в обороне; «Да. Знаю».
89. [Без ярости](89-without-rage.md) — Гайя держит Варга в тумане (титанская кровь не принимает бешенство); **Тейн поглощает туман вместе с Элирией**, держит Свет кольцом вокруг Тьмы.
90. [Мрогар](90-mrogar.md) — генерал был чемпионом, проигравшим Право; стаи воют, Гайя не один; **гибель Мрог'Зара**; Варг сдаётся.
91. [Достойный](91-worthy.md) — Скарн признаётся при всех; приговор снят; предатель-старейшина Хорн и схема; Брам и Скарн; курган Сайры.
92. [Война](92-war.md) — Салдар: «Моя очередь»; Ведар заканчивает ключ, король сомневается; **все Башни гаснут**; Драк'Кар, Ли'Зар, Харак'Шул; «Вместе — то, что не одному».

## Новые элементы (предложение)

| Элемент | Суть |
|---|---|
| **Этап Сферы 4 → второй узел** | Тейн поглощает Тьму на своих условиях — рядом с Элирией, Светом вокруг Тьмы. Прожилки идут рунными линиями, чёрная и белая рядом. |
| **Гибель Мрог'Зара** | Первый погибший генерал. Признание перед смертью: «Пусть вырежут мою зарубку рядом с твоей». |
| **Варг** | Сдаётся публично; становится братом Гайи. |
| **Скарн** | Признаёт удар и снимает приговор без суда. |
| **Старейшина Хорн** | Сторонник Салдара в роду; бежал; оставил схему со вторым узлом. |
| **Ключ Ведара** | Кольцо с пустым гнездом — артефакт, чтобы открыть второй узел в Тейне. Король ещё не решил. |
| **Башни гаснут** | Все «окна» Ведара открываются разом. |
| **Харак'Шул** | Появляется в финале во главе мёртвых. |

## Канонические ограничения

- Харак'Шул — некромант, четыре руки: посох, кинжал, щит, книга (по карточке генералов).
- Отец сбежал из-под охраны; король не решил судьбу ключа.
- Великая война начинается по старым договорам — Совет Четырёх.
