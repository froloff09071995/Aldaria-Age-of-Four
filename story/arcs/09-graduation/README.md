# Арка I.9 — Выпуск

**Статус:** черновик на согласование. **Финал арки I — Международная школа людей.**
**Формат:** визуальный сценарий; реплики главного героя (**Тейн**) помечены «ГГ».
**Период:** второе полугодие второго года: турнир, проекты, выпуск.
**Точка завершения:** Ли'Зар на крыше: «Нашла». Переход к арке титанов.

## Главы

39. [Турнир старших](39-senior-tournament.md) — реванш с ученицей-магом «без вспышки», финал против Торгара, Гайя первый в ремесле, групповая задача — первое место.
40. [Гайя и старший](40-gaya-and-the-elder.md) — Гайя мог победить и не ударил; «Потому что я не ты»; доклад посланника Вожаку.
41. [Выпускной проект](41-graduation-project.md) — Тейн «помнит» схему; Ведар велит убрать внутренний узел и тайно копирует её.
42. [Защита](42-defense.md) — проекты компании; все пятеро отличившиеся; награды.
43. [Закрытый фонд](43-closed-fund.md) — печать Совета эльфов, письмо Высокого дома, «погребена в Священном лесу»; «сначала — гора».
44. [Найдите меня](44-find-me.md) — «Магический Профиль», амулет для отца, взгляд отца на Ведара, слова Торгара, первое появление Ли'Зар.

## Основа

Каноническая [хронология второго года](../../02-school-years.md) и [образование](../../../lore/education.md); линии Сферы, Ведара и генералов из [генерального плана (PR #4)](https://github.com/froloff09071995/Aldaria-Age-of-Four/pull/4).

## Новые элементы (предложение)

| Элемент | Суть |
|---|---|
| **Ремесленный день турнира** | Новое испытание второго года; первое место — Гайя. |
| **Итоги турнира** | Личные — Торгар (финал против Тейна); магия — Элирия; ремесло — Гайя; группа — команда пятерых. |
| **Гайя не ударил** | Проигрывает старшему кузену, но вся школа видит выбор. Старший впервые сомневается. |
| **Схема амулета** | Кольцо, восемь лучей, узел — и внутренний второй узел «для чего-то второго». Ведар велит его убрать и копирует себе. Это след Сферы, принимающей второй источник. |
| **Все пятеро — отличившиеся** | Награды: Торгар — братство мастеров; Элирия — архивы старейшин; Дарион — наблюдатель на Совете Четырёх; Гайя — Арена без поручительства рода; Тейн — закрытый фонд. |
| **Высокий дом** | Мать — из Высокого дома эльфов; имя дома закрыто печатью Совета. |
| **Погребение в Священном лесу** | Мост к эльфийской арке. |
| **Амулет у отца** | Отец узнаёт схему и смотрит на Ведара. Подозрение. |
| **Ли'Зар** | Первое появление: тень с татуировками, «Нашла». |

## Канонические ограничения

- Выпускной проект Тейна — артефакт.
- Тейн получает расширенный доступ к библиотеке и узнаёт о знатном эльфийском роде матери.
- Слова Торгара о городе титанов — дословно по канону.
- Выпускники получают «Магический Профиль» с модулем «Инвентарь».
- Сфера по-прежнему не названа никем из персонажей.
