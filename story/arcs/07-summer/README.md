# Арка I.7 — Лето

**Статус:** черновик на согласование.
**Формат:** визуальный сценарий; реплики главного героя (**Тейн**) помечены «ГГ».
**Период:** каникулы между первым и вторым годом (1–2 месяца).
**Точка завершения:** Гайя после перехода едет в школу.

## Главы

31. [Какой она была](31-what-she-was-like.md) — отец рассказывает о Мираэль и о компании, отдаёт её учебную тетрадь; «откуда ты знаешь про трещину?».
32. [Где каждый](32-where-everyone-is.md) — Торгар в горе, видение Элирии в Священном лесу, Дарион и король в саду, фигура у Башни Света.
33. [Перелом](33-the-break.md) — первый переход Гайи, жрец, встреча со старшим кузеном, «он похож на мать».

## Новые элементы (предложение)

| Элемент | Суть |
|---|---|
| **Компания отца — шесть человек** | Отец, Мираэль, будущий король, титан, оборотень и ещё один. Имена не раскрыты. |
| **Загадку про конюшни придумала Мираэль** | Связь между путём первого года и матерью. |
| **Учебная тетрадь Мираэль** | Зелёный переплёт, схемы первого года, рисунки на полях. Помогает Тейну в магии второго года. Не тайные знания. |
| **Отец разбирается в кузне «немного»** | Зерно второй личности отца; не раскрывается. |
| **Отец Торгара узнаёт клеймо** | «Хороший мастер, не любит, когда о нём спрашивают». |
| **Видение Элирии** | Закрытый свет, чёрный дым, голос: «...оба...». Дальний намёк на два источника. |
| **Дарион отказывает отцу** | «Спроси его сам. Не через меня». Ничего не знает о Сфере. |
| **Фигура у Башни** | Рука Ведара у рун. Двусмысленно: чинит или вредит. |
| **Жрец видел отца Гайи** | «Большой. И грустный». Титанская кровь проснётся года через два. |
| **«Он похож на мать»** | Первое признание Вожака; Гайю сажают ближе. |

## Канонические ограничения

- Отец не раскрывает Сферу и обстоятельства гибели матери: «это не только моя тайна».
- Знатность рода матери не называется прямо.
- Переход Гайи — первый, волчий; титанский рост — позже (16–17 лет).
- Старший кузен и Гайя не дерутся.
