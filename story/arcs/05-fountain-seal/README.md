# Арка I.5 — Печать на фонтане

**Статус:** черновик на согласование.
**Формат:** визуальный сценарий; реплики главного героя (**Тейн**) помечены «ГГ».
**Период:** вторая половина первого года: экскурсия, несколько недель поисков, неделя испытаний.
**Точка завершения:** Тейн записывает имя матери в тетрадь.

## Главы

22. [Здесь проходили каждый день](22-every-day-path.md) — экскурсия, Галерея выпускников, паз в колонне, знак на фонтане.
23. [Не каждый знак — тайна](23-not-every-sign.md) — ложные следы, метод Гайи, первое касание печати.
24. [Я открыл](24-i-opened-it.md) — Гайя открывает проход один и возвращается за друзьями.
25. [Чужие неудачные работы](25-others-failed-works.md) — первая комната, записки к неудачным поделкам, первая загадка, решение не спешить.
26. [Семь дней](26-seven-days.md) — неделя испытаний, по дню на сцену.
27. [Не награда в руки](27-not-a-reward.md) — вторая комната, книга имён, общества других народов, скрытые привилегии, шарж с королём и отцом.
28. [Имя](28-the-name.md) — записка отца о рождении сына, запись матери, имя Мираэль.

## Основа

Эпизоды 18–24 черновика [первого года (PR #2)](https://github.com/froloff09071995/Aldaria-Age-of-Four/pull/2); каноническая [хронология школы](../../02-school-years.md) и [тайные сообщества](../../../lore/secret-societies.md).

## Новые элементы (предложение)

| Элемент | Суть |
|---|---|
| **Печать «Вместе — то, что не одному»** | Девиз Эльриха на фонтане. Печать ждёт касания двух народов сразу; Гайя несёт обе природы. Механика не объясняется глубже. |
| **Цепочка испытаний** | Загадка о конюшнях → старая кладка → пластина-карта → четыре рычага звонницы → копия с пропущенной строкой → оригинал хроники → пять рук на фонтане. Все подсказки показаны до разгадки. |
| **Клеймо на шкатулке** (гл. 25) | Молот, пересечённый клинком. Торгар «где-то видел». Это будущий след кузнечного псевдонима отца; раскроется у титанов. |
| **Книга имён** | Компания вписывает себя в список общества. |
| **Имя матери — Мираэль** | Рабочий вариант. Заменяется одним словом. |
| **Тейнаэль** | Тейн впервые узнаёт своё полное имя из записки отца. |
| **«И пусть дом простит меня»** | Эльфийская строка матери — намёк на конфликт с родом без его названия. |

## Канонические ограничения

- Первую комнату открывает Гайя; Тейн не повторяет это вместо него.
- Тайные привилегии раскрываются во второй комнате; решение добиваться их — во втором году.
- В архиве: король, отец, мать и другие члены общества.
- Тейн узнаёт имя матери, что она училась здесь и что была эльфийкой. **Знатность рода, герб и титул — не раскрываются** (это после выпуска).
- Сфера, война и обстоятельства гибели матери в документах не упоминаются.
- Элирия не решает загадки видениями: она видит только ману.

## Открытые вопросы

- Утвердить имя матери.
- Имя отца в подписях (в тексте — «имя отца ГГ»).
- Окончательные тексты загадок.
