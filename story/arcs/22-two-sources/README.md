# Арка V.3 — Два источника

**Статус:** черновик на согласование. **Финал всей истории.**
**Формат:** визуальный сценарий; реплики главного героя (**Тейн**) помечены «ГГ».
**Период:** три дня в искажённых землях, возвращение, месяц после войны; эпилог — через сорок лет.

## Главы

103. [Искажённые земли](103-twisted-lands.md) — кольцо Света вокруг отряда; «задача — довести»; Свет на исходе.
104. [Лиариэль держит](104-liariel-holds.md) — Ли'Зар разворачивается к теням: «Идите. Я держу»; «Мираэль гордилась бы».
105. [Мастер](105-the-master.md) — Ведар у источника; наставник сжёг вторую половину чертежей; нити Салдара ведут руку Ведара — ключ открывает второй узел.
106. [Салдар](106-saldar.md) — тысяча лет на ста шагах; его история и Альдарион; последний глоток Истока; «Руки!».
107. [Две руки](107-two-hands.md) — руки всех; **отец кладёт выпускной амулет — внешнее кольцо**; Тейн поглощает Чёрный источник; Салдар уходит с Альдарионом; «Узел по центру».
108. [Вернулась](108-returned.md) — Лиариэль свободна и умирает; Гайя несёт её в лес; единение рядом с деревом Мираэль; «ВЕРНУЛАСЬ».
109. [Хранитель](109-the-keeper.md) — Тейн принимает Исток и возвращает Свет дыханием; Эльрих засыпает навсегда; **цена: Тейн не стареет**; «Обещаю».
110. [Официальная версия](110-official-version.md) — тайный Совет: источники «уничтожены в войне»; коронация Дариона кривой короной.
111. [Эпилог. Кривой крючок](111-epilogue-crooked-hook.md) — сорок лет спустя; Торгар, Гайя, Дарион, Гаррет; новые ученики у фонтана; «Качается. Но держит».

## Как закрыты линии

| Линия | Развязка |
|---|---|
| **Сфера** | Два узла полны; кольцо — Свет изнутри и амулет снаружи. Тейн — хранитель обоих источников (утверждённый финал). |
| **Салдар** | Освобождён от источника, рассыпается; уходит в Мир Духов с Альдарионом. |
| **Ведар** | Одержимость → обратный удар Тьмы; последние слова: «Узел по центру». |
| **Лиариэль / Ли'Зар** | Держит тени ради отряда; освобождена; единение с лесом рядом с сестрой. |
| **Генералы** | Мрог'Зар (арка IV), Драк'Кар (гл. 99), Харак'Шул (гл. 100), Ли'Зар (гл. 108). |
| **Король Годрик** | Гибель с искуплением; «Ты — не цифра». |
| **Дарион** | Король; кривая корона. |
| **Торгар** | Убийца Драк'Кара, мастер с нишей, правитель титанов. |
| **Гайя** | Имя отца восстановлено; отказ от власти; брат Варга. |
| **Элирия** | Остаётся с Тейном (решение Д1). |
| **Гаррет** | Доживает рядом с сыном; похоронен в Саду памяти дома Иларэн рядом с Мираэль. |
| **Аэрис** | Передаёт хранение Истока внуку. |
| **Эльрих** | Окончательно становится деревом. |
| **Тайные общества** | Новые ученики открывают комнату под фонтаном; путь «начинается с кривого крючка». |

## Канонические ограничения

- Финал по решению автора: Тейн с помощью Сферы поглощает оба источника и становится их хранителем; для мира источники уничтожены во время войны.
- Цена финала — рабочее допущение Д1 (вечный хранитель; рядом Элирия).
