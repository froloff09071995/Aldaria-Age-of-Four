# Арка III.2 — Исток

**Статус:** черновик на согласование. **Центральная под-арка всей истории:** Тейн узнаёт, что в нём Сфера, и видит последнюю память матери.
**Формат:** визуальный сценарий; реплики главного героя (**Тейн**) помечены «ГГ».
**Период:** несколько дней.
**Точка завершения:** Тейн впервые сознательно касается Света — и пугается чёрной искры.

## Главы

68. [Совет старейшин](68-council-of-elders.md) — Элирия спорит, Аэрис: «Я рискую сердцем леса ради внука»; четыре на четыре, решает глава.
69. [Вода](69-the-water.md) — Скверна уходит, но **Сфера начинает пить Исток**; Аэрис не может закрыть; дерево открывает глаза.
70. [Эльрих](70-elrich.md) — Эльрих узнаёт работу «двух рук», называет **Сферу**; второй, пустой узел; учит закрывать: «Не держи. Дыши вместе с ним».
71. [Её дерево](71-her-tree.md) — последняя память Мираэль: активация, шатёр, «Живи. Просто живи»; Аэрис возвращает имя на камень.
72. [Бабушка](72-grandmother.md) — комната Мираэль, запись в книге рода: «Сын — хранитель по крови»; огонёк и чёрная искра.

## Новые элементы (предложение)

| Элемент | Суть |
|---|---|
| **Этап Сферы 3** | Резонанс со Светом: Сфера пьёт Исток. Остановлена Эльрихом. После этого в ней — глоток Света и **уголёк Тьмы** Драк'Кара. |
| **Эльрих** | Просыпается в дереве у водоёма. Знает о Сфере из «памяти леса» о Мираэль. Объясняет: Сфера сделана людьми по неполному знанию Альдариона, «принимает»; второе место — для другого источника; Салдар ищет сосуд. |
| **Видение матери** | Показан момент активации и внедрения Сферы; король — свидетель у шатра; «Её нельзя оставлять вещью. Вещь отнимут. А его — я спрячу». |
| **Тейн — хранитель по крови** | Запись в книге рода; Исток «поёт» для него. |
| **Аэрис — «бабушка»** | Возвращает имя дочери на камень. |

## Канонические ограничения

- Правду о Сфере Тейн узнаёт у эльфов, через лес и Эльриха; подробности (решения короля, пожар мастерской) остаются отцу.
- Сфера внутри Тейна — тайна; кроме Аэрис и Элирии, здесь о ней никто не узнаёт.
- Канон «Мира Эльриха»: он стал частью Священного леса и может пробуждаться, узнавать, отвечать и давать советы.
