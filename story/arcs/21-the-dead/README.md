# Арка V.2 — Мёртвые

**Статус:** черновик на согласование.
**Формат:** визуальный сценарий; реплики главного героя (**Тейн**) помечены «ГГ».
**Период:** месяц войны и сборы в поход.
**Точка завершения:** отряд входит в искажённые земли под кольцом Света Сферы.

## Главы

98. [Харак'Шул](98-harak-shul.md) — Западная равнина; павшие встают; Тейн упокаивает сотни, но Свет на исходе; связующий кинжал.
99. [Молот и обсидиан](99-hammer-and-obsidian.md) — в горе: Сигрун вырезает «руну наоборот» — холод; Торгар холодной ковкой разбивает **Драк'Кара**.
100. [Король пал](100-the-king-falls.md) — Годрик принимает кинжал за Тейна; Тейн рвёт руны клинка Светом «против пути»; **гибель Харак'Шула и короля**; «Ты — не цифра».
101. [Наследник](101-the-heir.md) — Дарион откладывает корону: «Сфера — не оружие королевства»; Аэрис — последний глоток Истока; «Запад».
102. [Дорога на запад](102-road-west.md) — отряд из девяти; сон Элирии: «Сосуд — не дверь. Сосуд — кольцо»; «Наконец-то»; Сфера очищает воздух вокруг отряда.

## Новые элементы (предложение)

| Элемент | Суть |
|---|---|
| **Гибель Драк'Кара** | Сигрун обращает приём Ведара во благо: руна жара «наоборот» — холод. Торгар разбивает генерала холодной ковкой. Хальгрим жив; Торгару — ниша в Зале Мастеров. |
| **Гибель Харак'Шула** | Тейн проводит Свет по связующему клинку «против пути»; добивают отец, Гайя, Варг. |
| **Гибель короля Годрика** | Закрывает собой Тейна. Искупление Г2. |
| **Дарион — король** | Корону наденет после войны. Первый указ: Сфера принадлежит только Тейну. |
| **Свет почти исчерпан** | Тьма в кольце больше Света — Салдар зовёт. |
| **Отряд** | Тейн, Элирия, Торгар, Гайя, Дарион, Гаррет, Варг, Брам. |
| **Эльрих и «Наконец-то»** | Подсказка: «сосуд — кольцо»; второй голос — Альдарион (не назван). |

## Канонические ограничения

- Сфера изначально создавалась, чтобы очищать от Скверны и поддерживать армию (по лору артефактов) — в походе она используется именно так.
- Генералы по карточкам: Драк'Кар — чёрное пламя, обсидиановый молот; Харак'Шул — четыре руки.
