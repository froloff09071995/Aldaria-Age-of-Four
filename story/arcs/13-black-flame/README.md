# Арка II.4 — Чёрное пламя

**Статус:** черновик на согласование. **Финал арки II — Город титанов в горе.**
**Формат:** визуальный сценарий; реплики главного героя (**Тейн**) помечены «ГГ».
**Период:** ночь нападения, две недели болезни и экзаменов, дорога к лесу.
**Точка завершения:** Тейн и Элирия входят в Священный лес; отец остаётся на границе.

## Главы

59. [Обсидиан](59-obsidian.md) — Драк'Кар выходит из шахты; Дарион ведёт эвакуацию по своей схеме; Гайя и Брам на мосту; Торгар держит мост.
60. [Чёрное пламя](60-black-flame.md) — **Сфера впервые поглощает Тьму**; «Хозяин был прав. Она жива»; «Башни стоят на земле, а мы — под ней».
61. [Прожилки](61-veins.md) — Скверна внутри Тейна, Хальгрим узнаёт тайну, лекарство — Священный водоём, письмо Элирии.
62. [Лицензии](62-licenses.md) — экзамены через боль, фонарь-оберег для рудокопов, «Инвентарь и Склад», клеймо «крючок и лист».
63. [Мальчик мой](63-my-boy.md) — Ведар и Ли'Зар: его настоящая цель; граница леса; «Посмотрим».

## Новые элементы (предложение)

| Элемент | Суть |
|---|---|
| **Драк'Кар** | Выходит снизу, под Башнями. Не забирает Тейна: «он сам придёт к нам». |
| **Этап Сферы 2** | Поглощает чёрное пламя; Скверна остаётся внутри Тейна прожилками. |
| **Хальгрим знает о Сфере** | Первый посторонний, которому открыта тайна. |
| **Лекарство — Священный водоём** | Причина ехать в лес становится вопросом жизни. |
| **Клеймо Тейна** | Крючок, обвитый листом. |
| **Ведар — открыто** | Работает с Тьмой, но ради «целой Сферы» с двумя узлами; «я использую его, как он — меня». Окна в Башнях — его, чтобы проверить отклик Сферы. Шахта семь — самоуправство Драк'Кара. |
| **Ли'Зар — посланница Салдара** | Знает, что Тейн едет к источнику Света. |
| **Элирия видит две маны отца** | «Мастер Гаррет. Мастер Терраг». |

## Канонические ограничения

- Отец не раскрывает Сферу: «расскажу всё, когда вернёшься из леса».
- Гайя — после первого перехода; второй ещё впереди. Он едет в степь, затем на Арену.
- Слово «Сфера» произносят только злодеи наедине; герои его не слышат.
- Тейн получает ремесленную и торговую лицензии, статус мастера и «Инвентарь и Склад» (по лору: для отличившихся выпускников титанов).
