# Арка III.1 — Под деревьями

**Статус:** черновик на согласование. **Начало арки III — Священный лес.**
**Формат:** визуальный сценарий; реплики главного героя (**Тейн**) помечены «ГГ».
**Период:** первая неделя в эльфийских землях.
**Точка завершения:** Аэрис соглашается сказать правду перед Советом старейшин.

## Главы

64. [Зелёный свет](64-green-light.md) — Сильваэн, Дом целителей: «только вода Истока»; герб-лист — дом матери.
65. [Высокий дом](65-high-house.md) — Владычица Аэрис, отказ: «человеческой крови нет места у Истока»; два портрета.
66. [Архивы](66-archives.md) — Тейн распускает узел трёхсотлетнего кристалла, Круг Корней, карта Лиариэль.
67. [Зачем ты пришёл](67-why-you-came.md) — Сад памяти, дерево матери со стёртым именем; почему союз был запрещён; «он был великодушнее нас».

## Новые элементы (предложение)

| Элемент | Суть |
|---|---|
| **Сильваэн** | Эльфийский город, выращенный в деревьях. |
| **Дом Иларэн — хранители Истока** | Решение Б1. Герб — лист, свёрнутый в кольцо (тот же, что на печати и подвеске). |
| **Владычица Аэрис** | Глава дома, бабушка Тейна. |
| **Почему союз запрещён** | Связь хранителей с Истоком передаётся только эльфийской кровью; у полукровки Исток либо молчит, либо «тянется к нему сам». |
| **Лиариэль** | Старшая сестра Мираэль, исследовательница Скверны из Круга Корней; ушла в искажённые земли за двадцать лет до войны; имя стёрто домом. (Решение Б3: будущая Ли'Зар.) |
| **Круг Корней** | Тайное общество эльфов-исследователей; знает, что Башни сделаны по чертежам Сферы. |
| **Дерево Мираэль** | Тело привезли с войны; дерево в Саду памяти, имя стёрто. |

## Канонические ограничения

- Мать — из знатного эльфийского рода; теперь раскрыт сам род.
- Сфера не названа героям; Круг не знает, что она в Тейне.
- Тейн не получает доступ к Истоку без решения Совета.
