# Арка IV.1 — Степь

**Статус:** черновик на согласование. **Начало арки IV — Великая Арена.**
**Формат:** визуальный сценарий; реплики главного героя (**Тейн**) помечены «ГГ».
**Период:** первая неделя на Арене. Тейну 18 лет.
**Точка завершения:** на Арену прибывает «посол короля людей».

## Главы

78. [Город боёв](78-city-of-fights.md) — степь, Великая Арена, Гайя после второго перехода; «...хорошее место...».
79. [Право](79-the-right.md) — требование «голоса», четыре боя; Скарн назначает Варга; история Мрогара.
80. [Знак Клыка](80-mark-of-the-fang.md) — однорукий оружейник помнит Гаррета; слепой бой с Элирией в роли глаз; предупреждение о пустынях.
81. [Шёпот](81-whisper.md) — Салдар говорит с Тейном во сне у Чёрного источника; «возьми мою руку, когда будет нужно».
82. [Первые бои](82-first-fights.md) — Гайя побеждает, не переходя в полную форму; Торгар больше не самый большой.

## Новые элементы (предложение)

| Элемент | Суть |
|---|---|
| **Варг, Скарн** | Имена старшего кузена и Вожака. |
| **Право Гайи — «голос»** | Не власть, а право требовать суда для отца. Три боя от жрецов + четвёртый в Кровавую битву против бойца рода. |
| **Варг — боец рода** | Назначен отцом; сомневается открыто. |
| **Мрогар** | Бывший лучший боец Арены, проиграл Право, ушёл в пустыни. (Будущий Мрог'Зар.) |
| **Знак Клыка** | Объединение достойных бойцов Арены; испытание доверием. |
| **Сфера хранит «взгляд» Элирии** | Тейн едва видит ману сквозь повязку. |
| **Салдар говорит с Тейном** | Через уголёк Тьмы; облик — только силуэт. Уголёк растёт. |
| **Полная форма Гайи** | Непредсказуема; однажды он потерял себя на ночь. |

## Канонические ограничения

- Право достойности назначают жрецы; испытание — выдающееся достижение или серия публичных боёв.
- Гайя после второго перехода — около 2–2,5 м; полная трансформация может достигать 3–4 м.
- Салдар привязан к Чёрному источнику и не может от него уйти.
