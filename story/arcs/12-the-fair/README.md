# Арка II.3 — Ярмарка

**Статус:** черновик на согласование.
**Формат:** визуальный сценарий; реплики главного героя (**Тейн**) помечены «ГГ».
**Период:** Ярмарка мастеров и несколько недель после неё.
**Точка завершения:** из шахты семь поднимается Тьма.

## Главы

55. [Ярмарка мастеров](55-masters-fair.md) — Тейн находит Террага по рукам, кривой крючок вместо заказа, «Нашёл».
56. [Две руки](56-two-hands.md) — тайная мастерская, два профиля, история Арены; предупреждение наставника; подозрение на Ведара; «скажу после леса».
57. [Король в горе](57-king-in-the-mountain.md) — Совет в горе, Дарион-наблюдатель; король предлагает «защиту короны»; «мне понадобится оружие».
58. [Шахта семь](58-shaft-seven.md) — перерезанные руны, обсидиановая каверна, голос: «...вот где ты прятался...».

## Новые элементы (предложение)

| Элемент | Суть |
|---|---|
| **«Терраг» придумала Мираэль** | «Чтобы любой, кто тебя любит, мог найти». |
| **Подвеска-лист** | Отец делал её для Тейна и каждый год уносил с Ярмарки обратно. |
| **Отец подозревает Ведара** | Один из мастеров пропал при пожаре, бросившись к чертежам; тело не нашли. Подозрение, не доказательство. |
| **Тот, кто объяснит** | Отец отправляет Тейна в Священный лес к «тому, кто знает больше» (Эльрих, имя не названо). |
| **Король — «серый» (Г2)** | Предлагает Тейну мастерскую «под защитой короны»; хочет использовать Ведара; «он — и то, и другое». |
| **Дарион** | «Тогда я выберу за тебя». Не знает о Сфере. |
| **Тьма снизу** | Башни не действуют под землёй; руны крепления в шахте перерезаны приёмом братства. |

## Канонические ограничения

- Отец раскрывает вторую личность, но не Сферу: «скажу после леса».
- Король хранит тайну, но его государственный интерес теперь открыт отцу.
- Совет Четырёх не принимает решения — только наблюдение.
